    Architecture & stack

    Frontend  Next.js + Tailwind + ECharts
API       FastAPI (REST + WebSocket)
Workers   Prefect/Celery (nightly pipeline)
DB        PostgreSQL + TimescaleDB
Files     S3/R2 (benchmark .h5/.parquet)
ML        ONNX Runtime (CJM, DRL agent)
Auth      Supabase  ·  Billing Razorpay+Stripe
Host      Fly.io / Render / Hetzner
MVP path  Streamlit + HF Spaces (free)
    Nightly pipeline: fetch → GARCH norm → SSCDV → CJM → TVP‑VAR/QQC → SHAP → publish JSON → alerts.
